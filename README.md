# Bean Boom 🫘

**[▶ Play now at bb.superzan.net](https://bb.superzan.net/)** — free, no download, works on desktop and mobile browsers.

A minesweeper game with a unique perler-bead (bedded art) visual style.

## Features

- Three difficulty levels: Easy, Medium, Hard
- Global leaderboards (daily / monthly / all-time)
- Paid challenges with full refund on goal completion
- English & Chinese UI (manual switch)
- Guides: [How to Play](https://bb.superzan.net/how-to-play) · [Patterns](https://bb.superzan.net/minesweeper-patterns) · [Strategy](https://bb.superzan.net/minesweeper-strategy) · [Tips](https://bb.superzan.net/minesweeper-tips) · [History](https://bb.superzan.net/minesweeper-history)

## Tech Stack

- Vanilla JavaScript + [Vite](https://vitejs.dev/) multi-page build
- Deployed on Cloudflare Pages (auto build on push to `master`)

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
```
