## 1. itch.io（★★★ 首选，最简单）

- **地址**：https://itch.io/game/new
- **类型**：HTML5 上传游戏（可 zip 打包构建产物，或直接外链）
- **模式**：选 "Embedded in page" + 勾选 "Mobile friendly"
- **Kind**: HTML5 · **Release status**: Released · **Inputs**: Mouse, Touch
- **Tags**: minesweeper, puzzle, logic, browser, casual
- **填表要点**：Cover 图 630×500（icon-512 裁切）；说明区贴中描述 + 2 张截图 + Play 链接
- **费用**：免费（可选付 itch 分成）
- **效果**：dofollow 外链 + itch 社区导流，indie 圈标配

## 2. CrazyGames（★★★ 流量大，需审核）

- **地址**：https://developer.crazygames.com/（注册开发者账号）
- **类型**：HTML5 游戏发行（需要嵌入他们的 SDK 才能上主站，投稿前先邮件问）
- **流程**：提交游戏资料 → 审核（1-4 周）→ 通过后按其 SDK 规范接入
- **效果**：若通过，日均导流量可观（他们的 puzzle 品类流量大）
- **备注**：若不想接 SDK，只提交"外链收录"型条目即可拿外链

## 3. GameDistribution（★★☆ HTML5 分发网络）

- **地址**：https://gamedistribution.com/register（publisher 账号）
- **类型**：上传 HTML5 zip 包，他们分发到数千个合作游戏站
- **收入**：广告分成模式
- **备注**：需要游戏内嵌他们的广告 SDK；若不想加广告，跳过此站

## 4. Poki（★☆☆ 门槛高）

- **地址**：https://developers.poki.com/
- **备注**：对独立游戏有专门通道，但审核严格、通常要求独占性或深度定制。可作为远期目标，暂缓。
